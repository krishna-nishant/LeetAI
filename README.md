# LeetAI - Enhanced LeetCode Clone

This project is a LeetCode clone with significant enhancements to the learning experience, developed for the Level Up: Vibe Coding Hackathon.

## Features

### Original Features (LeetCode-like)

- Problem listing and detail pages
- Code editor with language selection
- Dark/light theme toggle
- Similar visual appearance and UI elements

## Main Enhancements Over LeetCode

### 1. AI Explanation Feature ✨

Unlike LeetCode's limited explanations, our AI-powered system provides comprehensive learning support:

- **Approach Discussions**: Detailed explanations of multiple solution strategies
- **Step-by-Step Hints**: Progressive hints that guide without spoiling the solution
- **Full Solution Walkthroughs**: Complete explanations with time/space complexity analysis
- **Interactive Learning Flow**: Users can choose their preferred learning style

### 2. YouTube Solution Integration 📺

We've seamlessly integrated curated YouTube solutions directly into the problem interface:

- **Tutor Filtering**: Find explanations from your favorite educators
- **Language Filtering**: Focus on solutions in your preferred programming language
- **Embedded Video Player**: Watch solutions without leaving the platform
- **Visual Integration**: Clean UI that maintains focus on the problem-solving experience

### Note on Demo Implementation

For this hackathon demo, we've implemented toast notifications to indicate features that are not yet fully functional. These toasts are not considered an enhancement over LeetCode, but rather a way to provide feedback during demonstration.

## Technology Stack

- React.js for the user interface
- Tailwind CSS for styling
- React Router for navigation
- CodeMirror for the code editor

## Setup and Installation

1. Clone the repository

```
git clone https://github.com/krishna-nishant/leetai.git
```

2. Install dependencies

```
npm install
```

3. Run the development server

```
npm run dev
```

## Deployment

The application is deployed at [https://leetai-vibe.vercel.app](https://leetai-vibe.vercel.app)

## Hackathon Submission

This project was created for the Level Up: Vibe Coding Hackathon, where participants were challenged to:

1. Pick a real-world website
2. Recreate it faithfully
3. Add meaningful enhancements

Our enhancements focus on revolutionizing the learning experience by providing AI-powered explanations and integrated video solutions - two features that significantly improve upon the original LeetCode platform's educational capabilities.
